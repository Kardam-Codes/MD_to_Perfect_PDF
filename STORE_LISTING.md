## 📝 Full Description
Transform your Markdown documents into professional, print-ready PDFs with MD → Perfect PDF - the privacy-first Chrome extension for developers who care about formatting.

## 🌟 Key Features:

📝 **Live Markdown Editor**
- Real-time preview as you type
- Syntax highlighting for code blocks
- Dark and light themes
- Resizable editor and preview panels

🎨 **Advanced PDF Export**
- Multiple page sizes (A4, Letter, Legal)
- Portrait and landscape orientations
- Customizable margins (compact/normal/spacious)
- Font selection (Inter, Roboto, Serif)
- Headers, footers, and page numbers
- Manual page breaks with ---

🔒 **100% Privacy First**
- No cloud uploads or data collection
- Everything processes locally in your browser
- No account required
- No tracking or analytics

⚡ **High Performance**
- Fast PDF generation
- Browser pooling for speed
- Rate limiting and security
- Optimized for large documents
